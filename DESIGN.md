# DESIGN.md — Redline Editorial

The design system for **At0micenergy** (saiprasad-cybsec.com). Dark-first, editorial,
terminal-flavored. The whole site should feel like a zine made by someone who lives
in a terminal — opinionated, slightly raw, hand-built. If it ever looks like it could
have been generated, something went wrong.

## Palette

Three colors. Restraint is the brand.

| Token      | Hex       | Role                                              |
|------------|-----------|---------------------------------------------------|
| `--bg`     | `#0E0B0B` | Page background (near-black, warm — never pure)   |
| `--bg-raise` | `#171212` | Raised surfaces: cards, callouts, code chrome    |
| `--bg-deep`  | `#0A0808` | Sunken surfaces: ticker, code bodies, series band |
| `--ink`    | `#EFE8DC` | Primary text (warm off-white)                     |
| `--ink-dim`| `rgba(239,232,220,.62)` | Secondary text                          |
| `--ink-faint` | `rgba(239,232,220,.38)` | Tertiary / metadata                    |
| `--line`   | `rgba(239,232,220,.14)` | Hairline borders                            |
| `--accent` | `#FF4D2E` | Signal red-orange. Sparingly: eyebrows, numerals, italics, rules, hovers |
| `--accent-deep` | `#C93318` | Accent hover/darker states                   |

Paper (light) theme inverts surfaces: bg `#EFE8DC`, ink `#16110C`, accent unchanged.
Accent-on-dark contrast: `#FF4D2E` on `#0E0B0B` ≈ 5.9:1 (WCAG AA). Ink-on-bg ≈ 16.1:1.

**Forbidden:** purple/blue/pink gradients, glassmorphism, default framework blue,
stock illustrations, abstract blobs, emoji as icons.

## Typography

| Role | Stack | Usage |
|------|-------|-------|
| Display | **Instrument Serif** 400 (+ italic) | Hero, post titles, pull quotes, footer sign-off, big numerals. Serif *italic* in accent color = the editorial voice. |
| Body / UI | **Space Grotesk** (variable 400–700) | Everything structural: section heads, cards, body copy, nav. Section heads use the variable weight driven by scroll velocity. |
| Labels / code | **JetBrains Mono** (variable + italic) | Eyebrows, metadata, buttons, code, terminal chrome, captions. |

Type scale: display `clamp(4rem, 14vw, 15rem)` hero → `clamp(2.4rem, 5.5vw, 4.6rem)`
section heads → `1.0625rem/1.7` body. Post body measure: **65ch**.

All fonts are self-hosted (`assets/fonts/`, woff2), preloaded in `<head>`. No webfont
service dependency.

## Voice

First person, practitioner's notebook. Eyebrows are terminal comments (`// …`).
Buttons are commands (`Browse all posts →`). The 404 admits the page "escaped the
sandbox." Never address the reader as a security professional; conditional branches
("if you have a security background… otherwise…") preserve the teaching order.

## Layout

- `--pad: clamp(24px, 5vw, 72px)` page gutters; `--section-gap: clamp(84px, 12vh, 160px)`.
- Home: left-aligned hero (never centered), ticker, asymmetric 12-col bento
  (7/5 → 4/4/4 → full-bleed feature rhythm), pinned series band, about teaser.
- Post: chapter numeral + title + meta + "why read this" hook, then 65ch article
  with sticky TOC on desktop.
- Breakpoints: 640 / 960 / 1280.

## Components

- **Preloader** (`_includes/preloader.html`, `assets/js/preloader.js`): terminal boot,
  <2s, skippable (click/key), once per session (`sessionStorage`), instant-skip for
  repeat visits and `prefers-reduced-motion`.
- **Custom cursor** (`cursor.js`): fine pointers only; dot → ring on links → filled
  disc with `READ` on post cards. Touch devices never see it and lose nothing.
- **Ticker**: pure-CSS marquee of top tags, pauses on hover, `aria-hidden`.
- **Post cards** (`post-card.html`): bento spans by position, red edge-rule grows on
  hover, mono numeral + date, hook (front-matter `hook:` or excerpt fallback).
- **Series tracker** (`series-tracker.html`, `_data/series.yml`): 7 steps with
  `published/draft/planned` states; progress bar; pinned horizontal scroll on desktop,
  vertical stack on mobile. Add parts by editing the YAML — no code changes.
- **Post template**: chapter numeral (series part or №), reading time
  (`words/180+1`, Liquid — no plugin), tags, hook callout; sticky TOC generated by
  `toc.js` (also numbers `h2`s as §01…); code blocks get terminal chrome + copy
  button via `code.js`; callouts via `.callout` (default), `.warn`, `.tip`;
  `.why-note` renders only when a post sets `why:` in front matter; series prev/next
  renders only for posts with `series_part:`.
- **Posts index** (`layouts/posts.html` + `filter.js`): tag filter buttons with
  counts, two-phase fade/stagger transitions, live result count.
- **Theme toggle** (`theme.js`): `data-theme="ink|paper"` on `<html>`, persisted to
  `localStorage`, instant (no transition flash on load).
- **404**: giant accent `404` with scramble effect, terminal error line, two exits.
- **Footer**: RSS link, "Built by hand with Jekyll · no trackers · no blobs" colophon.

## Motion rules

1. **Boot** <2s, once per session, skippable. Never blocks content on repeat visits.
2. **Scramble/decode** on the hero headline and the 404 numeral only — never body text.
3. **Scroll choreography is scrubbed/pinned**, not fade-up-on-scroll: hero parallax,
   pinned horizontal series timeline, clip-path curtain reveals for framed media and
   post images. (Generic fade-up is banned.)
4. **Section titles**: Space Grotesk variable weight follows scroll velocity
   (`velocity.js`, 560→840) and relaxes at rest. Serif italic accents never move.
5. **Split reveals**: `[data-split]` headings mask-reveal word by word on entry.
6. **Easing**: `--ease-out` for UI, `--ease-snap` for wipes. Never the same easing
   everywhere; motion must read as *caused* by the content.
7. **GPU-friendly**: transforms and opacity only; `will-change` on animated tracks.
8. **Reduced motion**: all JS motion modules no-op; boot is skipped; content is fully
   visible with zero animation. CSS animations are neutered.
9. **Touch**: no cursor, no hover-dependent content; pinned series becomes a vertical
   stack; filter/ticker/TOC all work without hover.

## Performance rules

- LCP budget ~1.5s: self-hosted preloaded fonts, single compressed stylesheet,
  `defer`red scripts, no render-blocking JS. CDN libs (GSAP, ScrollTrigger, Lenis)
  are `defer`red and **guarded** — the site is fully readable with them blocked.
- No JS framework. No build-time plugins outside the GitHub Pages whitelist
  (only `jekyll-sitemap` is used).

## Accessibility

- Skip link, semantic landmarks, `aria-label`s on nav/TOC/filter.
- Focus-visible: 2px accent outline.
- Contrast: ink 15:1, accent 7.2:1, dim text 6.4:1 on bg.
- Decorative motion layers (`grain`, ticker, cursor) are `aria-hidden` / pointer-events-none.

## Adding content

- **New post**: drop a Markdown file in `_posts/` with `title`, `date`, `tags`,
  `excerpt` (used as the "why read this" hook). Optional: `hook:`, `why:` (author
  note), `series_part:` (series prev/next + chapter numeral).
- **New series part**: edit `_data/series.yml` — set `status: published` and `url:`
  when the post lands.
- **Author photo**: add `img/author.jpg`, set `author-avatar: author.jpg` in
  `_config.yml`. The about page and home teaser pick it up; until then a labeled
  placeholder frame renders (never an illustrated avatar).
- **Callouts in posts**: `<div class="callout"><span class="callout-tag">Lab note</span><p>…</p></div>`
  (add `warn` / `tip` class for the variants).

### Bugs found and fixed during QA (2026-09-27)
- `cl()` helper calls inside `:root` custom properties were passed through literally
  (`cl(4rem, …)` is not valid CSS) — Sass only evaluates functions in custom properties
  when interpolated. Fixed with `#{cl(...)}`; documented in `_tokens.scss`.
- Boot theatre ran ~4.5s (sequential typing + no auto-dismiss). Rewrote to overlapping
  lines at 5ms/char with auto-dismiss after last line + hold: <2s total.
- `toc.js` greedy regex `^§\d+` ate the author's own "1." heading numbers ("§011." →
  ". Start…"). Now strips author numbering and replaces it with the §NN kicker.
- Mobile header hid Series/Tags/About (only Posts kept). Now a two-row header on ≤640px.
- Dead HTB badge embed (`hackthebox.eu/badge/427574` 404s after redirect). Replaced with
  the current `hackthebox.com/badge/image/427574` image badge (200 image/png verified).
